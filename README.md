## Run
```
$ node nu demo.nu
```

For now, this will automatically generate 3 files

1. `output/demo.js` (executable output)
2. `output/demo-parsed.json` (parsed tree structure for debugging)
3. `output/demo-analysis.json` (static analysis info)
